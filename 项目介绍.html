// problem_to_product

求职信息很多，但下一步不清楚。

项目针对计算机求职过程中最常见的三个断点，把“材料、判断、行动”连接起来。

01 / 材料分散

简历和岗位要求无法对齐

用户知道自己做过什么，却很难快速判断哪些经历应该突出、哪些技能还没有被岗位看见。

02 / 判断模糊

岗位很多，不知道是否值得投

只看岗位标题容易误判。真正需要的是技能、经验、项目和要求之间的可解释匹配结果。

03 / 行动断裂

投递之后，准备和跟进容易丢失

简历优化、面试练习、求职信和投递状态分散在不同工具里，无法形成连续的工作流。

// end_to_end_workflow

从一份简历开始，走完一条求职链路。

Agent 不只负责聊天，而是把求职过程拆解成可执行、可检查、可持续推进的步骤。

01

建立求职画像

解析简历中的经历、技能、项目和目标偏好，形成后续分析的统一输入。

resume → profile
02

导入与搜索岗位

导入岗位、面经和本地知识，支持按关键词、城市和薪资进行检索。

jobs → retrieval
03

匹配与找差距

输出匹配分、覆盖技能、部分覆盖和缺口，并解释分数来自哪里。

jd × resume → score
04

准备面试材料

生成定制简历草稿、求职信、面试题和答题提示，围绕目标岗位准备。

gap → preparation
05

持续追踪投递

维护投递记录、状态、备注和提醒，形成从申请到面试的行动看板。

apply → follow up
// jobhunt_capabilities

真正面向求职任务的 Agent 能力。

功能不是泛化的聊天入口，而是围绕求职者每天会做的具体动作组织起来。

一个 Agent，覆盖五类关键工作。

领域工具负责确定性处理，Agent 负责理解上下文、组合能力和给出下一步建议。用户可以通过 CLI 或 Web UI 使用同一套业务逻辑。

RESUME → JOB → MATCH → PREPARE → TRACK
01 / RESUME

简历解析与优化

解析简历结构、技能和经历，计算 ATS 维度，并根据目标 JD 生成针对性修改建议。

02 / JOB SEARCH

岗位导入与检索

支持岗位、面经和知识文档导入，基于 RAG 检索岗位信息和相关准备材料。

03 / JOB MATCH

岗位匹配与技能差距

计算技能、经验、学历、项目等维度的匹配结果，输出覆盖项与缺口证据。

04 / INTERVIEW

面试与算法练习

按岗位和目标公司生成面试题、答题提示，并优先结合本地导入的面经知识。

05 / MATERIAL

求职信与职业路径

基于简历和 JD 生成个性化求职信，并从画像推导职业方向、里程碑和补强技能。

06 / APPLICATION

投递看板与提醒

记录公司、岗位、渠道、状态和备注，限制状态非法回退，并提供跟进提醒。

// built_on_openharness

重点是求职应用，底座复用 OpenHarness。

OpenHarness 是骨架，不是页面主角。它让我可以把精力集中在求职领域逻辑，而不是重新搭建 Agent 基础设施。

01
Agent loop 与上下文组装复用消息循环、模型调用、上下文和求职画像注入，让 Agent 能根据任务组合多个求职工具。
02
Tools / Skills / Plugins 机制复用工具注册和技能加载机制，把简历、匹配、面试、求职信和投递能力接入统一入口。
03
RAG、记忆与本地会话复用知识检索、会话恢复和本地存储思路，支持岗位库、面经和用户画像持续积累。
04
权限、CLI 与 Web API复用权限检查、命令体系和 API 层，让求职功能同时支持安全执行、终端演示与 Web 仪表盘。
// tomorrow_demo_script

现场演示：展示一次真实的求职决策。

建议不要从底层架构开始讲，直接拿一份简历和一个目标岗位，展示 Agent 如何给出有依据的下一步。

三分钟演示顺序

从用户问题开始：“这份简历适合不适合这个岗位？我下一步该做什么？”

1解析简历，展示技能、经历和 ATS 信息。
2导入或搜索 Python 后端岗位，查看 JD 结构。
3运行岗位匹配，展示分数、覆盖技能和 3 个差距。
4继续生成面试准备或新增一条投递记录，形成闭环。

可以直接复制的演示命令

离线环境也可以演示，使用 hash embedding 避免依赖外部模型。

oh job-hunt setup --yes --embedding-provider hash
oh job-hunt resume parse ./examples/sample_data/resume.md
oh job-hunt import --dir ./examples/sample_data/jobs --collection jobs
oh job-hunt match --resume ./examples/sample_data/resume.md --jd ./examples/sample_data/jobs/python-backend.md
uv run --extra web oh job-hunt web --host 127.0.0.1 --port 8000
