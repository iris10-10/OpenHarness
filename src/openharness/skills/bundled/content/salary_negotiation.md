# 薪资谈判技能

帮助用户科学谈薪：市场基准定位 → 总包核算 → 话术准备 → 谈判推演。目标是在保持 offer 安全的前提下争取合理涨幅。

## 何时使用

- 用户被问期望薪资，不知道怎么报数
- 用户拿到 offer 想 argue / 比较多 offer
- 用户想搞懂总包构成（base / 奖金 / 股票 / 补贴）
- 用户被压价，需要应对策略

## 工作流程

### 1. 市场基准定位

用 `salary_query` 查目标岗位 × 城市 × 年限的市场分位（P25/P50/P75），多城市或多公司用 `salary_compare`。结合用户现状（`profile_query` 读取当前薪资与年限）确定谈判目标区间：

- 现薪为锚：健康跳槽涨幅 20%-30%，低于 15% 需要有非薪资理由
- 市场为锚：目标定在 P50-P75 之间；手里有竞争 offer 时可锚定 P75+
- 输出三档：理想值 / 满意值 / 底线值（低于底线准备放弃）

### 2. 总包核算

按下方公式把所有 offer 折算成**年化现金 + 股票年化**统一口径，再对比（详见"总包计算公式"）。注意五险一金缴纳基数、绩效系数真实性（问清是"保底"还是"平均"）。

### 3. 话术准备

按场景给用户话术模板（见"谈判话术库"），让用户改成自己的语气演练一遍。所有话术遵循：**不撒谎、不报虚数、不贬低对方公司**。

### 4. 谈判推演

模拟 HR 压价 / 拖延 / 打感情牌等场景（可结合 interview_sim 技能演练），准备用户的两套预案（HR 答应加薪 / 坚持原价）。

### 5. 注意事项交代

时机（见"时机与红线"）、书面确认、竞业与试用期条款提醒。

## 总包计算公式

```
年总包 = 月 base × 年薪月数（含 13/14/15 薪结构）
      + 年终奖（月 base × 绩效系数 × 年终月数，按保底值算）
      + 股票/期权年化（总价值 ÷ 归属年数，注意行权价与税）
      + 补贴（餐补/房补/交通，月度 × 12）
```

对比口径提醒：

- **现金为王**：base 与奖金是确定性收益；股票要打折评估（未上市期权按 0-30% 期望值、上市公司 RSU 按授予时点价格 × 0.7-0.9 折算波动）
- 月薪涨幅 ≠ 总包涨幅：注意"15 薪但绩效系数 0.6"这类结构性压价
- **税与社保基数**：股票归属按工资薪金计税；公积金/社保按 base 缴纳的公司，base 高的 offer 隐性价值更大
- 拿到数字后必须让对方发**书面 offer（含薪资结构明细）**，口头承诺一律不认

## 谈判话术库

**被问期望薪资（报数）**：
> "我目前月薪 X，年包约 Y。结合岗位职责和市场行情，期望月薪在 [满意值]-[理想值] K 之间，具体可以结合整体 package 谈。"
（要点：报区间不报单点；先亮现薪做锚；把话题引向总包。）

**Argue offer（礼貌争取）**：
> "非常感谢这个 offer，我对团队和业务都很有兴趣。不过坦白说，这个数字和我目前的情况/手上的其他机会有差距（当前年包 X / 另一个 offer 年包 Y）。如果能到 [目标值]，我可以直接推进流程、尽快入职。"
（要点：表达入职意愿在先；给具体依据而不是"我觉得少了"；给出成交条件。）

**HR 压价"预算有限"**：
> "理解预算约束。那我们看看结构：base 不变的情况下，签字费 / 股票 / 年终保底 / 职级，任何一项能补上差距都可以聊。"
（要点：把单一维度僵局变成多维度组合。）

**HR 问"手上还有哪些 offer"**：
> "有在看几个机会，其中 [A 公司同方向] 已经到终面/给了条件。但我更倾向贵司的 [具体业务/团队原因]，所以希望薪资上能让合作尽快定下来。"
（要点：可以模糊但不撒谎；强调倾向性给对方安全感。）

**HR 拖延"要审批"**：
> "没问题，那我 [具体日期] 前等你消息。另外我这个流程和其他机会的截止时间比较接近，如果审批周期长，能否先给我一个书面意向？"
（要点：给 deadline 而不是无限等；要书面意向保底。）

## 时机与红线

**好时机**：
- 拿到口头/书面 offer 之后（主动权最大，argue 成功率最高）
- 手里有 2+ 个 offer 互相竞争时
- HR 主动问期望薪资时（必须报，回避会显得没准备）

**坏时机**：
- 简历筛选 / 非终面阶段主动谈钱（除非 HR 先问）
- 背调开始后再大幅 argue

**红线**：
- 不编造不存在的竞争 offer（背调/圈子小容易穿帮）
- 不接受"入职后再调薪"的口头承诺（要写进 offer）
- 不在拿到书面 offer 前拒绝现有 offer 或现有公司提离职
- 拒绝时留余地、不撕破脸（"这个数字确实有差距，如果后续有空间随时联系我"）

## 输出要求

- 所有薪资数字结论标注来源（salary_query 结果 / 用户提供 / 通用经验区间）
- 市场数据缺失时明确说"这是通用经验区间，建议用 salary_query 或招聘平台验证"
- 总包对比一律输出表格（公司 × 口径 × 数值）
- 不替用户决定接/拒；给出建议区间与理由，决策权在用户
