# 八股文题库技能

计算机基础知识面试问答辅导：按方向与考察频率组织题库，用统一答题模板训练"结构化表达"，并沿追问链深挖到底层原理。

## 何时使用

- 用户提到八股文 / 刷面试题 / 基础知识复习
- 用户问某个具体概念（"讲讲 TCP 三次握手""Redis 持久化"）
- 用户想按方向（操作系统 / 网络 / 数据库 / 语言）系统刷题
- 用户即将面试，需要高频题冲刺

## 工作流程

### 1. 确定方向与范围

确认用户的目标岗位方向（后端 / 前端 / 算法 / 数据 / 测试 / 运维）与面试公司；有 JD 时用 `jd_parse` 提取技能要求，按 JD 权重排题；有目标公司时先用 `rag_search_interview` 找该公司真实考过的题（优先级最高）。

### 2. 选题与出题

从下方题库按"方向相关 → 考察频率"排序出题，一次一题。练习模式先让用户作答，讲解模式直接输出答案（用答题模板组织）。

### 3. 讲评

对照答题模板点评：结构是否完整、深度是否够（有没有到底层原理）、是否覆盖高频追问点。给出一版"参考答案"。

### 4. 举一反三

沿追问链延伸 1-2 层（"面试官接下来大概率会问……"），并推荐相邻题目。

## 答题模板（所有概念题通用）

```
1. 一句话定义（结论先行，30 秒内）
2. 为什么存在 / 解决什么问题（设计动机）
3. 怎么工作（核心机制，配合关键参数/数据结构）
4. 对比同类（A vs B，各自的适用场景）
5. 实战关联（我在项目中怎么用/踩过什么坑）+ 已知边界（什么场景不适用）
```

示例（TCP 三次握手）：`TCP 是面向连接的可靠传输协议，连接建立需要三次握手（定义）；目的是同步双方初始序列号并确认双向收发能力，两次不安全、四次浪费（动机）；流程为 SYN → SYN+ACK → ACK，序列号用于去重与有序性（机制）；与 UDP 对比：可靠有序 vs 低延时无连接（对比）；项目中 HTTP 长连接复用减少握手开销，TIME_WAIT 过多时调整复用参数（实战）。`

## 题库（按方向分类，★ 为高频）

### 操作系统
- ★ 进程 vs 线程 vs 协程：资源占用、切换成本、通信方式（追问：协程为什么轻、线程崩溃为什么进程也崩）
- ★ 虚拟内存与页表：地址翻译、缺页中断、TLB（追问：页面置换算法 LRU/LFU、大页）
- ★ 用户态/内核态：切换时机（系统调用/中断/异常）、上下文切换成本
- ★ 死锁：四个必要条件、预防/避免/检测、银行家算法
- ★ IO 模型：阻塞/非阻塞/IO 多路复用（select/poll/epoll 区别）/信号驱动/异步（追问：epoll LT vs ET、惊群）
- 内存管理：brk/mmap、内存池、slab
- 零拷贝：mmap + write / sendfile / splice

### 计算机网络
- ★ 三次握手 / 四次挥手：状态机、TIME_WAIT 意义（追问：为什么不能两次、大量 TIME_WAIT/CLOSE_WAIT 排查）
- ★ TCP 可靠性：滑动窗口、超时重传、快重传、拥塞控制（慢启动/拥塞避免/快恢复）
- ★ TCP vs UDP 与应用选择
- ★ HTTP/1.1 vs HTTP/2 vs HTTP/3：队头阻塞、多路复用、QUIC
- ★ HTTPS 握手：证书链、非对称交换对称密钥、中间人防护（追问：TLS1.3 改进）
- 从 URL 输入到页面渲染（综合题：DNS → TCP → TLS → HTTP → 渲染）
- Cookie/Session/JWT/Token 鉴权对比

### 数据库 / MySQL
- ★ 索引原理：B+ 树为什么（vs B 树/哈希/跳表）、聚簇 vs 二级索引、回表与覆盖索引
- ★ 索引失效场景：函数计算、隐式转换、前导模糊、最左前缀
- ★ 事务 ACID 与隔离级别：脏读/不可重复读/幻读、MVCC、间隙锁
- ★ 锁：行锁/表锁/间隙锁/Next-Key、死锁排查
- 慢查询优化：explain 执行计划、慢日志
- 日志体系：redo/undo/binlog、两阶段提交、主从复制与延迟

### Redis
- ★ 数据结构与底层：SDS、跳表、压缩列表/listpack（追问：为什么用跳表不用 B 树）
- ★ 持久化：RDB vs AOF、混合持久化
- ★ 缓存三兄弟：穿透（布隆过滤器/空值）/ 击穿（互斥锁/逻辑过期）/ 雪崩（随机 TTL/多级）
- ★ 分布式锁：SETNX + 过期时间、看门狗续期、RedLock 争议
- ★ 过期与淘汰策略：惰性+定期删除、8 种淘汰策略
- 主从/哨兵/集群：槽分配、脑裂

### 语言基础（按用户方向选）
- **Java**：★ JVM 内存区域与 GC（分代/收集器/调优）、★ HashMap 原理与并发问题、volatile/synchronized/锁升级、线程池参数与拒绝策略
- **Go**：★ goroutine 调度 GMP、★ channel 原理与死锁、GC（三色标记）、sync.Map/mutex
- **C++**：★ 智能指针与循环引用、★ 虚函数表与多态实现、内存对齐、移动语义
- **Python**：★ GIL 与多线程适用性、★ 协程 asyncio 事件循环、装饰器/生成器、引用计数 GC
- **前端**：★ 事件循环与宏微任务、★ 闭包与作用域链、原型链、跨域方案、渲染性能

### 数据结构与算法概念
- ★ 各排序复杂度与稳定性（追问：为什么快排不稳定、外部排序）
- 哈希冲突解决与扩容
- 一致性哈希（分布式缓存场景）

## 出题与讲评规则

- **一次一题**，用户答完再讲评；练习时先不给答案
- 讲评对照答题模板五段：缺哪段点哪段
- 深度要求：Senior 岗必须能答到第 3 层追问（机制 → 原理 → 边界/源码级细节）
- 题目优先级：目标公司真实面经（RAG）> JD 技能对应题 > 方向高频题
- 概念讲解标注"高频指数"（★ 数），帮用户分配复习时间
